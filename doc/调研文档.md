# 图标生成器 · 功能需求文档

> 版本：v1.0　|　日期：2026-09-09　|　调研对象：当前实现 `icon.html` + 竞品 `https://www.fuwa.org/tools/icon-generator.html`

---

## 一、产品定位

一款**零安装、全浏览器运行**的在线图标制作工具，面向网站开发者、UI 设计师、移动应用开发者、社交媒体运营者等，帮助用户快速生成高质量的应用图标、网站 favicon、社交媒体头像。

核心价值：**5 分钟内从零产出可下载的多尺寸图标包**，无需注册、无需设计软件、无需后端服务（纯前端 Canvas + SVG）。

## 三、详细功能需求

### 模块 1：图标内容来源（P0 必须）

| # | 功能 | 描述 | 优先级 |
|---|------|------|:------:|
| 1.1 | 文字图标 | 输入 1~3 个字符（支持中英文、数字、符号），实时渲染到画布。当前已实现，保留。 | P0 |
| 1.2 | 上传图片 | 支持拖放或点击上传 PNG / SVG，最大 2MB。图片作为图标主体，可缩放。SVG 需渲染到 Canvas 保证下载兼容性。 | P0 |
| 1.3 | FontAwesome 图标 | 输入 FA 类名（如 `fa-heart`）或从常用图标面板点选，渲染到 Canvas。依赖 FontAwesome 5+ CDN。 | P1 |

**交互**：三种来源用 Tab 切换，默认"文字图标"。切换时清空当前画布并使用默认参数重新渲染。

## 四、技术架构建议

```
icon.html（单页应用，纯前端，零后端）
├── 渲染层：HTML5 Canvas 2D（主）+ SVG（导出时重建）
├── 样式：Tailwind CSS 3（预编译 CDN + 双 CDN 回退）
├── 图标库：FontAwesome 4/5（CDN）
├── 字体：Google Fonts（CDN，按需加载中文字体）
├── 压缩：JSZip（用于多尺寸打包下载）
├── 无框架：原生 JS，IIFE 模块封装
└── 本地运行：file:// 即可（已验证），无需 HTTP 服务
```

### 关键实现细节

| 难点 | 方案 |
|------|------|
| Canvas 中文渲染 | 中文字体通过 Google Fonts `<link>` 预加载，`document.fonts.ready.then(...)` 等待加载完成后再 drawText，避免豆腐字。 |
| SVG 导出 | 不做 Canvas → SVG 栅格跟踪（复杂且不精确），而是用 DOM API 以 `<svg>` 字符串形式**重建**图标：形状用 `<circle>/<rect>/<polygon>`，文字用 `<text>`，图片用 `<image>`。 |
| 渐变绘制 | Canvas `createLinearGradient / createRadialGradient / createConicGradient`，锥形渐变需检查浏览器支持性（Chrome 99+ / Safari 16.4+），不支持时降级为线性。 |
| 阴影 | Canvas `ctx.shadowColor / shadowBlur / shadowOffsetX / shadowOffsetY`，注意：阴影会被形状裁剪，绘制顺序为：先画背景形状 → 设置阴影 → 画图标内容 → 关闭阴影。 |
| 透明背景 | 下载 PNG 时直接用 canvas.toDataURL 即可（Canvas 默认背景透明）；显示给用户预览时 Canvas 本身就是透明的（body 背景透出）。 |
| 多尺寸 ZIP | 对同一组参数，循环设置 `canvas.width/height` 为目标尺寸，`drawIcon()`，然后 `canvas.toBlob()` → JSZip。 |
