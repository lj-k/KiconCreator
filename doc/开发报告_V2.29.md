## 3. 方案要点

- **零依赖打包**：项目约束"只包含 js 和 html、无后端"，浏览器无原生 zip 接口 → 新增 pack.js 自实现 ZIP（STORE 法 + CRC32 + UTF-8 名）；图标本为高压缩比内容，STORE 不引入明显体积损失。
- **任意尺寸渲染**：复用 `renderSnapshotThumb` 快照管线（上限 64→1024），避免"主画布位图缩放"导致小尺寸糊化；这也保证了"zip 内每个尺寸 = 预览缩放效果"。
- **ICO**：PNG-in-ICO 容器（Vista 起标准），6 尺寸全内嵌；替代旧的"PNG 改名 .ico"。
- **统一出口**：任一打包勾选 → 整次下载为 zip（主格式 + codeChk 附加 canvas/json + rawChk 附加原图），zip 内命名沿用需求 2.35；json 入 zip 复用导出预设语义（含剪裁图片导出方式询问，可取消）。
- **原始图片来源**：`entry.src`（上传时原始 dataURL）优先，预设导入图回退 `imgFullDataURL`（未剪裁整图）；行 + 填充色块引用去重收集。
